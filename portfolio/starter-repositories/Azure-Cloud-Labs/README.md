# Azure Cloud Labs

Hands-on, reproducible learning exercises for Microsoft Azure and hybrid infrastructure.

## Planned contents

- Azure landing-zone concepts and governance
- Identity and access management patterns
- Network connectivity and segmentation labs
- Monitoring, backup and recovery exercises
- Secure VM and workload deployment
- Cost awareness and operational guardrails

## Safety

Use a dedicated test subscription, least-privilege identities, budget alerts and synthetic data. Never commit secrets, tenant identifiers or production configuration.
