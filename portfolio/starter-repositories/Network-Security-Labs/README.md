# Network Security Labs

Vendor-neutral networking and infrastructure security labs using synthetic topologies.

## Planned contents

- IP addressing and subnetting examples
- Routing, switching and DNS troubleshooting
- Firewall policy and network segmentation exercises
- VPN and secure remote-access concepts
- Load balancing and application delivery concepts
- Packet analysis using generated or sanitized captures

All diagrams, addresses, hostnames and packet captures must be synthetic or explicitly cleared for public release.
