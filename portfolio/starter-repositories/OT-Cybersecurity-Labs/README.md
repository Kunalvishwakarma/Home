# OT Cybersecurity Labs

A learning portfolio for industrial and operational technology cybersecurity.

## Planned contents

- Purdue model reference diagrams
- IEC 62443 concepts: zones, conduits and security levels
- OT asset inventory and risk-assessment templates
- Secure remote access and segmentation patterns
- OT incident-response and recovery exercises
- IT/OT boundary and monitoring concepts

Labs must be isolated and non-production. Do not connect experiments to live industrial control systems or publish sensitive operational details.
